# Generating k-shot SMILEs strings with Llama

Here we can test out Llama's ability to produce SMILES strings without any fine-tuning.

The `gen_0_shot.py` and `gen_k_shot.py` files are meant to be used with an environment that can run inference, such as ana-env. The `guacamol_analysis.py` file is meant to be used with the [guacamol package](https://github.com/BenevolentAI/guacamol)
